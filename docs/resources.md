# Workshop resources and further reading

Use this page as the shared reading list for the workshop. The links are
grouped by how they are used so participants can distinguish the hands-on path,
official platform context, and broader industry perspectives.

## Canonical hands-on references

- [OpenSpec](https://openspec.dev/) is the workshop's specification-driven
  development framework. Teams use it to turn an issue into reviewed
  requirements, scenarios, design decisions, and bounded tasks.
- [GitHub Agentic Workflows](https://github.github.com/gh-aw/) is the primary
  reference for authoring natural-language workflows that compile into GitHub
  Actions with sandboxing, scoped permissions, and safe outputs.

Repository instructions, the active OpenSpec change, checked-in workflows, and
pinned tool versions remain authoritative for the exercises. External
documentation provides context; it does not override repository guardrails.

## Official GitHub context

- [GitHub Agentic Workflows is now in public preview](https://github.blog/changelog/2026-06-11-github-agentic-workflows-is-now-in-public-preview/)
  explains the public-preview status, GitHub Actions integration, and
  security-first model.
- [Spec Kit](https://github.com/github/spec-kit) is GitHub's toolkit for
  structured specification-driven processes. Lab 1 compares its concepts with
  OpenSpec, while OpenSpec remains the single hands-on workshop path.
- [How to bring your software delivery workflow into GitHub with agent apps](https://github.blog/ai-and-ml/github-copilot/how-to-bring-your-software-delivery-workflow-into-github-with-agent-apps/)
  illustrates how agent apps bring delivery context and specialized services
  into GitHub rather than forcing developers to move context between tools.

## Broader Agentic SDLC perspectives

- [Agentic SDLC Guidebook](https://agenticsdlc.github.io/agentic-sdlc-ops/)
  presents values and principles centered on visibility, governability,
  planning, verification, repository ownership, and lifecycle clarity.
- [The Agentic SDLC Handbook](https://danielmeppiel.github.io/agentic-sdlc-handbook/)
  is a practitioner-oriented, evolving handbook for designing reliable and
  maintainable agent-first engineering systems.

These resources are recommended further reading, not additional required frameworks.
The workshop demonstrates one concrete implementation:

> OpenSpec defines change intent, harness engineering makes repository context
> executable, and GitHub connects issues, Copilot sessions, pull requests,
> Actions, security, Azure deployment, GH-AW, and durable evidence.

## Suggested reading path

1. Read the OpenSpec home page before Lab 1.
2. Skim Spec Kit during the Lab 1 comparison.
3. Read the agent apps article before Lab 2.
4. Review the GH-AW home page and public-preview announcement before Lab 5.
5. Use the Guidebook and Handbook after the workshop to compare operating
   models and identify practices to adopt in your own organization.
