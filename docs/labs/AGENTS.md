# Lab authoring guide

Each lab document must contain:

1. a measurable outcome;
2. prerequisites;
3. participant steps;
4. expected repository artifacts;
5. verification commands;
6. a time-boxed recovery path;
7. an optional stretch task.

Do not hide required commands in instructor notes. Keep the happy path achievable within the agenda and move exploratory comparisons into optional sections.

Use PowerShell-compatible commands. Distinguish repository artifacts that
participants can inspect from external organization or Azure configuration that
instructors must prepare. Each lab must leave a durable GitHub or repository
receipt that a reviewer can inspect without the originating agent conversation.
